# حزمة الدورة المستندية والمحاسبية لمصنع الأثاث

مصنع أثاث مكتبي ومنزلي حسب طلبات العملاء في السعودية.

## الملفات

- [تحميل الحزمة كاملة ZIP](factory-accounting-package.zip)
- [الدليل والنماذج PDF](factory-accounting-guide.pdf) — 54 صفحة و35 نموذجًا.
- [الدليل والنماذج Word](factory-accounting-guide.docx) — نسخة قابلة للتعديل.
- [حاسبة التسعير والسجلات Excel](factory-pricing.xlsx) — 16 ورقة تشمل المواد والعمل والتحميل والتسعير ومقارنة التقديري بالفعلي.

للتنزيل من صفحة ملف في GitHub، استخدم **Download raw file**. يمكن أيضًا تنزيل المستودع كاملًا من **Code → Download ZIP**.

## المحتوى

المبيعات والتصميم والتعاقد، المشتريات والموردون، المخزون، أوامر الإنتاج، الجودة والهالك، التسليم والتركيب، الدفعات، القيود المحاسبية، مراكز التكلفة، الإقفال، وآلية التسعير بهامش الربح والعمولة والخصم والضريبة.

## الاستخدام

استبدل بيانات المثال بتكاليف المصنع الفعلية، واعتمد الصلاحيات والسياسات والمعدلات قبل التطبيق. في Excel الخلايا الزرقاء للمدخلات والرمادية للمعادلات. استبدل سطر المثال الإجمالي بالتفاصيل دون جمعهما معًا. الحاسبة للطلب كاملًا؛ قسّم على عدد الوحدات فقط إذا كانت متجانسة.

الأرقام ونسب الدفعات وحدود الاعتماد أمثلة وليست أسعار سوق أو متطلبات ملزمة. الحزمة أداة إجرائية وتقديرية، وليست نظام فوترة إلكترونية أو دفتر أستاذ، وتخضع التفاصيل الضريبية والمحاسبية لمراجعة المسؤول المالي وفق وضع المنشأة والمتطلبات السارية.

الإصدار 1.0 — 28 أكتوبر 2026.
